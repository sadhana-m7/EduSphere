# EduSphere — Learn. Share. Verify. Grow.

EduSphere is a community-driven learning platform designed to help learners discover, share, evaluate, and learn from educational resources in a more structured and transparent way.

The platform addresses a common challenge in online learning: **finding educational content is easy, but determining whether it is relevant, current, and trustworthy can be difficult.**

## 🚀 Live Demo

**[EduSphere — Live Demo](https://edusphere-lyart-rho.vercel.app/)**

## 🎯 Problem Statement

The internet provides an enormous amount of educational content, but learners often face difficulties in:

* Finding relevant resources for their learning goals
* Identifying current and useful learning materials
* Distinguishing popularity from reliability
* Understanding why a resource should be trusted
* Organizing resources according to their skills and career interests

EduSphere aims to bring these needs together in a single learning ecosystem.

## 💡 Solution

EduSphere combines **resource discovery, sharing, verification signals, evidence, and personalized learning tools** into one platform.

Instead of treating popularity or upvotes as proof of accuracy, EduSphere provides multiple signals that help learners make more informed decisions about the resources they use.

### Core Principle

> **Popularity ≠ Accuracy**

AI-assisted analysis is designed as a supporting layer rather than an absolute source of truth, while community verification and evidence provide additional context.

## ✨ Key Features

### 🔎 Resource Discovery

* Search educational resources by subject, resource type, language, and freshness
* Browse resources shared by learners and educators
* Save resources for later use

### 📤 Resource Sharing

* Share learning materials such as PDFs, lecture notes, slides, videos, and study guides
* View contributor information and resource metadata

### 🛡️ Trust & Verification

* AI-assisted verification workflow
* Community verification
* Trust and freshness indicators
* Evidence-based resource information
* Reporting for incorrect, outdated, misleading, or duplicate resources

### 🧠 Personalized Learning

* Connect resources with individual skill and career interests
* Generate learning-focused activities around resources
* Support different learning preferences

### 📚 Learning Tools

* AI-assisted summaries
* ELI5-style explanations
* Flashcards
* Quizzes
* Study plans
* Audio-based learning

### 👥 Learner & Educator Profiles

* Separate learner and educator experiences
* Contributor points and badges
* Verification history
* Resource contribution tracking

### 🏆 Community Contribution

* Contributor rankings
* Reputation indicators
* Recognition through badges and contribution points

> Contribution and popularity are treated separately from factual accuracy.

## 🧪 Current MVP

The current version focuses on demonstrating the **core product experience, interface, workflow, and trust model**.

The MVP uses frontend state and representative/mock data for several workflows. AI-assisted features are represented through the prototype experience rather than being connected to a live AI backend.

This approach allowed us to validate the product concept and user journey while keeping the prototype focused and functional.

## 💻 Getting Started

### Prerequisites

Make sure you have installed:

* [Node.js](https://nodejs.org/)
* [pnpm](https://pnpm.io/)

### Installation

Clone the repository:

```bash
git clone <repository-url>
cd <project-folder>
```

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Open:

```text
http://localhost:3000
```

### Production Build

To create a production build:

```bash
pnpm build
```

To run the production build:

```bash
pnpm start
```
